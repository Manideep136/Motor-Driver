# Motor-Driver

Welcome to the **DRV8833 Dual H-Bridge Motor Driver** project! This repository contains open-source hardware files for a compact and reliable PCB designed to control small DC motors and stepper motors in robotics and embedded systems. 

---

## ✨ What Does This Project Do?
This circuit board acts as the "muscle" for your microcontroller (like an Arduino, ESP32, or STM32). While microcontrollers can think and process data, they cannot provide enough electrical power to drive motors directly. This board uses the **DRV8833 chip** to take low-power signals from your microcontroller and safely translate them into high-power motion for your motors.

---

## 🛠️ Key Features
- **Dual Motor Control:** Independently control the speed and direction of up to **two DC motors** (or one stepper motor).
- **Built-In Safety:** Features internal overcurrent protection, short-circuit protection, and thermal shutdown to prevent the board from burning out.
- **Low Voltage Operation:** Works smoothly with low-voltage power supplies (ranging from 2.7V to 10.8V).
- **PWM Speed Control:** Allows smooth speed variations using Pulse Width Modulation signals.
